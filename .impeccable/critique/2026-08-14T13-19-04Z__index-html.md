## What's Working

1. THE "CURRENT ROLE" SIGNAL IS EXEMPLARY STATUS DESIGN. Four job titles at identical display-2 scale would be a flat list. The pulsing halo plus the pill straddling the card edge on translate-middle-y answers "which is now?" in under a second with no reading. It encodes a temporal fact in a temporal channel rather than asking text to carry it, so it survives a scan that reads nothing — and experiences.css:33-38 substitutes a static ring under reduced motion, preserving information while dropping animation.

2. THE CPB DIAL HAS AN INVARIANT, ENFORCED IN CODE. --cpb-radius and --cpb-circumference declared once (cpb.css:12-22); cpb.js:29-32 reads circumference back via getComputedStyle with numeric fallback. Geometry cannot drift between SVG dash array and JS offset math because there is only one number. Rewind logic checks boundingClientRect.top > 0 to distinguish leaving downward from upward, so replay fires only on scroll-back. Someone reasoning about state, not copying a snippet.

3. MOTION DISCIPLINE IS CONSISTENT ENOUGH TO COUNT AS A DESIGN POSITION. Seven subsystems, seven opt-outs, zero exceptions — dials, Swiper (autoplay AND transition speed), pulse, back-to-top morph, card transitions, scroll-behavior, AOS.
